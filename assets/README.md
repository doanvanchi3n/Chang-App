# Tài nguyên ứng dụng

| Thư mục | Nội dung |
| --- | --- |
| `images/` | Ảnh minh họa, ảnh nền |
| `icons/` | Icon riêng của thương hiệu |
| `animations/` | Animation linh vật |
| `audio/` | Âm thanh tập trung |
| `fonts/` | Font Inter và giấy phép đi kèm |

Chưa có tài nguyên. Chỉ tạo các thư mục trên khi thêm file thật, rồi khai báo
đường dẫn tương ứng trong phần `flutter.assets` hoặc `flutter.fonts` của
`pubspec.yaml`. Chỉ đặt `fontFamily: 'Inter'` sau khi có font và khai báo đầy đủ.
Không đặt file môi trường hoặc khóa bí mật vào assets.
